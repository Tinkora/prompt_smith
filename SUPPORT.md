## Questions and Bugs

Use [GitHub Issues](https://github.com/Tinkora/prompt_smith/issues) for
reproducible bugs and focused feature requests. Use
[GitHub Discussions](https://github.com/Tinkora/prompt_smith/discussions) for
usage questions and compatibility evidence.

Include the selected dialect, the smallest template that reproduces the result,
the expected diagnostic or render, browser and operating system versions, and
whether the problem also occurs in the relevant upstream framework. Redact
credentials and private prompt content before posting.

## Security

Follow [SECURITY.md](SECURITY.md) for private vulnerability reports. Do not put
sensitive security details in a public issue or discussion.

## Funding
